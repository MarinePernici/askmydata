# Diagrams

This folder contains architecture and design diagrams for AskMyData.

Diagrams are written with PlantUML in order to keep them versioned, maintainable and readable directly from the repository.

## Current diagrams

| File | Description |
|---|---|
| `use-cases.puml` | UML use case diagram describing the main interactions between the user, the AI agent and the data source. |

## Rendering

The diagrams can be rendered with:

- PlantUML extension in VS Code
- PlantUML command line
- online PlantUML server
